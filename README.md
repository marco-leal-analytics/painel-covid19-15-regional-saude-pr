# painel-covid19-15-regional-saude-pr
Painel interativo desenvolvido em parceria com a UEM e a 15ª Regional de Saúde do Paraná para monitoramento da COVID-19. Utilizando R e Shiny, a solução transforma dados epidemiológicos em indicadores e visualizações dinâmicas, apoiando a análise da incidência, evolução dos casos e tomada de decisão em saúde pública.
